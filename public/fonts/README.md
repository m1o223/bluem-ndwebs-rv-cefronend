# Local webfonts

- **Playfair Display** (Latin and Latin Extended variable webfonts, weights 400–900) is used for English and Swedish site text. Official source: https://github.com/google/fonts/tree/main/ofl/playfairdisplay
- **Noto Naskh Arabic** (Arabic variable webfont, weights 400–700) is used for Arabic site text. Official source: https://github.com/google/fonts/tree/main/ofl/notonaskharabic

Both families are distributed under the SIL Open Font License 1.1. License copies are stored in `licenses/`.
